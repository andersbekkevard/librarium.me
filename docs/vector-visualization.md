### Vector space visualization
Create a vector space of books and view them as a graph for an interactive experience.
Make this the focal point of the app, that is, this is the actual "Librarium" you can enter.

Add an AI chat on the side in a UI component like Eden, that you can talk to while traversing the graph.
This AI will be cheap and useful, because it will have json context on the graph, or perhaps through a tool, so it can get good context on "why item x and item y are connected in this way"

This is a great way to
- Work with vector spaces (Linear Algebra, AI concept)
- Work with AI applications and prompt engineering
- Lay the groundwork for ML visualizations and ML reccomendations
- Practice Algorithms and Datastructures

Map by
- Reading proximity
- Genres shared
- Words in reccomendations - semantic analysis
- Reviews (?) or other googlebooksapi data
